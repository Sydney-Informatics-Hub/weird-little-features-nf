# `assets/`

You can store auxillary files that your workflow may need in here. We don't recommend storing data in your git repository but if you had a samplesheet you'd like to use for automated testing then it could be placed here. Additionally, you may wish to store the following:

- [MultiQC config YAML files](https://docs.seqera.io/multiqc/getting_started/config)
- Logo image files
- Email templates (e.g. nf-core/sarek email [.txt](https://github.com/nf-core/sarek/blob/master/assets/email_template.txt) and [.html](https://github.com/nf-core/sarek/blob/master/assets/email_template.html))
- [A samplesheet schema JSON file](https://nextflow-io.github.io/nf-schema/latest/nextflow_schema/sample_sheet_schema_specification/)
